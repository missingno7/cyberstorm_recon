## New matches and measured codegen facts

All results use pinned Watcom 10.6 wpp386 through repository wrappers, `-4s -s -oxt -bm -oe`.

1. **Declaration order inside an expanded helper can change its caller while preserving the helper.** In `SurfaceApplyNoiseDetails`, declaring squared width before the descriptor pointer, instead of after it, leaves the standalone 144-byte helper STRICT and repairs all 15 register bytes in `SurfaceInitializeProcedural` (224 bytes). `procedural_details.tpl.c` tested **8** width/descriptor ordering and accessor forms; choices **1 and 3** make details, procedural initialization and color mapping all STRICT. Choice 0 retains the D15 caller. Final source retains choice 1.
2. **Counter declaration order and post-call data-pointer capture repair SurfaceApplyNoise.** `int i; unsigned int row;`, followed by the original assignments/loops, puts outer row at `[esp+4]` and descriptor index at `[esp]`. Capturing the data pointer after `next_link_seed`, then advancing it and storing through it, restores pointer EAX/value DL. `apply_declarations.tpl.c` tested **6** counter-order × pointer/member/reference access forms. Choice **0** is STRICT 256 bytes; reversing just these counters in that form is D138. The reference-accessor counterpart with the original order is D3. This is a local context result, not a general ordering rule.
3. **Setter local declaration order is independently visible.** Declaring `y` before `x`, then assigning x first and y second, makes the unchanged array-store expression STRICT for all 96 bytes of `SurfaceGridSetValue`. `setter_declarations.tpl.c` tested **6** order × direct/staged-address forms. Choice **0** is STRICT; declaring x before y with the same assignments/store is D28. Six `setter_method.tpl.c` alternatives and six pointer/const-pointer/reference `setter_point.tpl.c` alternatives did not solve it.
4. **This large function does not acquire another recursive expansion from the tested inline pragmas.** At depth 1, 2 or 8, recursion on and off give the baseline D5221 recursive body. Depth 0 suppresses helper expansion and gives much shorter, nonmatching code. Explicit inline keywords on adjustment/noise/table helpers (`explicit_inline.tpl.c`, **8** combinations) also leave the two large target diagnostics unchanged. These observations concern this source and flags; they do not establish that the pragmas never work.
5. **Standalone byte equality does not establish formal parameter widths.** `average_formals.tpl.c` / `expand_input_types.tpl.c` show that wide arithmetic-helper formals with explicit short captures can preserve both standalone helpers while changing the expansion caller substantially. The wider-input expansion reached 2128 bytes with frame b0, versus target 1792/frame b4. The final source retains the published short formals.
