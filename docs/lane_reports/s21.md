- `004155dc` is the generated `MissBrief` destructor. The candidate starts from the published `shell/missbrf.c` and replaces its synthetic initializer scaffolding with real global class objects; all nine accepted functions remain STRICT.
- `004155fc..00415a85` is one packed debriefing-screen object. No original path string was found; `MissionDebrief` is a working name. The next bytes are linker padding.
- `00426cdc..00427262` is the base-control/drawing object. `00427264` and `00427268` are its inline virtual Event/Draw COMDATs. The emitted base vtable and type descriptor prove both identities.
- The heuristic `0042726c..004279fc` range contains **two objects**: surface code ends at `004275ba`; two zero linker-fill bytes precede the polygon object, whose 32-byte switch-table prefix starts at `004275bc` and first function starts at `004275dc`. Combining them emits `8bc0` alignment at `004275ba` instead of the original zeros. The split is preserved in separate candidate files.
- `00427c68..00427e0c` is the bitmap/background object. Its second function jumps to the first function's EBP epilogue; this is evidence that both belong together.
- `00429708`, `0042974c`, and `00429790` are shared inline destructor COMDATs from the existing `gui/menu.c`; they are banked in a copy of that TU with zero losses.
- `004297d4..00429a02` plus `00429a04/1c/24/3c` are one polygon-resource source TU and its class COMDATs. Its real global arrays generate the two constructor-array calls. `0042c9d0` is an additional shared trivial destructor already counted elsewhere.
- `00429a44..00429ea3` is a native C++ range-widget object compiled with `plain-oe`; `00429ea4..0042a0df` is a separate palette object. Their distinct alignment, static timer, and different data ownership agree with the split.
