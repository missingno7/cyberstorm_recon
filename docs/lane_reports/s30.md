## Code-generation facts and evidence

All observations use pinned Watcom C++ 10.6, `plain-oe` (`-4s -s -bm -oe`) unless stated otherwise. They are context-specific compiler observations, not claims about historical source names.

1. **Branch-local raw values in a shared scale helper affect caller allocation.** `scale-matrix.tpl.c` crosses result initialization, four small-case caps and four large-case caps (32 compiled). Uninitialized common result plus branch-local `adjusted` and conditional result assignment recovers ChangeMorale, AdjustFatigue and AdjustMorale together. Promotion `actor.matrix.promote.txt`: new 3 / lost 0. Nearby models recover the same callers but lose FatigueCost; those were rejected (`actor.branch.promote.txt`). Standalone Scale remains DIFF.
2. **A named floating-point value can prevent stack-slot reuse.** RemainingValue with a named `float value=descriptor->value` reserves 0x1c; re-reading the descriptor value twice with explicit float casts reserves original 0x18 and is STRICT 110 B. `remaining-lifetime.tpl.c` has 8 valid forms; only alternative 0 is STRICT. Final-context rerun gives the same result (`final-dispatch-context.txt`). No precision-changing rewrite or cast to double was adopted.
3. **Mutating the fixed-point delta before shifting changes nested inline temporaries.** `delta=-delta; *value-=delta<<12` retains the 43-byte standalone helper and the accepted single-skill function, but changes the loop's register/stack context. Together with reverse injury-branch orientation it recovers AdjustSkills, including its jump into the prior epilogue. `injury-branches.txt`: alternatives 0/1 give AdjustFixed, AdjustSkills and AdjustSkill STRICT, with Recovery D3. Receipt `actor.injury.promote.txt`: new 5 / lost 0 relative to the original published actor TU.
4. **The experience loop is a nested call and the shifted scalar must be captured before the indexed threshold test.** Typed descriptor thresholds at +0x2f, `U32 integral=experience>>12`, then the comparison, followed by `ActorAdjustSkills(s,1)` yield STRICT 160 B. `gain-integral.tpl.c` tests 6 forms: alternative 0 STRICT; reusing an earlier total is D3, captured descriptor D8, byte/int level captures worse. `actor.gain.promote.txt`: new 6 / lost 0. Directly spelling the fixed loop loses the original negative-delta temporary/branch retained by nested inlining.
5. **Aggregate initialization/assignment and an explicit memcpy are different allocator contexts.** The Herc list needs a block copy of the two widths. A local `{25,40}` initializer makes its function STRICT but grows _DATA from 12 to 20 bytes and loses initializer/data proofs (`session.list.promote.txt`), so it was rejected. `Columns columns=g4941ec` copies the existing object and preserves all data proofs. In `columns.tpl.c`, five aggregate assignment/address forms are STRICT; explicit memcpy is D214, despite representing the same eight-byte copy. `session.columns.promote.txt` banks 453 bytes with lost 0.
6. **Per-caller coordinate context can repair a later backward tail while protecting earlier users.** `geometry-calls.tpl.c` tests all 8 subsets of three conversion callers. Converting only 0043d2b9 to the already-defined helper safely recovers 0043dad7; changing 0043c5d6 loses the four published early tail users. `session.geometry-calls.promote.txt`: 66 functions / 7540 bytes, new 2 / lost 0. The rejected all-helper context is recorded in `session.context.promote.txt`.

Negative flag controls: `actor.flags.txt` deliberately tests default inline optimization versus size/extra optimization because retained switch bodies and tail merging were unresolved: baseline 33/47, -oex 9/47, -oes 0/47; unsupported -oeh produced no usable object. The extra string containing a leading space was rejected and is not evidence. `actor.inline-limit.txt` tests the specific inlining-threshold question: -oe=50 gives 28/47, 80 gives 29/47, 100 gives 33/47, 200 gives 29/47.
