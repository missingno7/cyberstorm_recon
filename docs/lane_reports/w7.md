- ActorListTransfer: compare.py --at ActorListTransfer=4565e0 showed the out-of-line getter form ended at 704 bytes. A separate inline getter used only in transfer, followed by objdis.py beside show.py 4565e0, expanded it to the target's 992-byte extent and moved the first mismatch from +8 to +6. The standalone ActorGetByIndex remained strict. The remaining prologue mismatch is a 0x1c versus 0x18 stack frame and ESI versus EBX parameter placement.

The first remaining mismatch is the loop exit path; the target branches to a shared return tail before this function.
- ActorFindFree: changing the flag typedef from unsigned to signed char changed the anchored difference from 14 to 13 bytes, while the first mismatch remained the byte predicate at +47.
- WorldActionClear: show.py 457250 shows saves for EBX/ESI/EDI/EBP and a stream reload from the argument slot; candidate objdis.py saves only EBX/ESI and keeps the stream in ESI. The current first mismatch is +2, with 54 bytes differing.
- WorldActionInitialize: show.py 456f90 points both assert calls at 004a0524; the candidate CONST reference binds to 004a0515. The 15-byte prefix experiment fixed the relocation only while shifting the assert source lines, so it was not adopted.
- Static initialization: ActorListGlobalObject actorListGlobalObject(actorListDescriptor); generates W?.fn_init$n()v, which compares STRICT for 48 bytes at 004561d0; no handwritten initializer was used.
