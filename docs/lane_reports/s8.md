## Object boundaries and source model

* `00433640..004349c0`: `terr\tbuild.c`, profile `ot`. The loader's assertion supplies the filename, at source line 93. All entries are aligned to 16 bytes. The generated module-registration/static-initialization body is STRICT, as are its initialized `_DATA` (`004905f8`) and `CONST2` (`0048db08`) references. The call at `00433645` is generated `__wcpp_2_mod_register_`; the pre-existing readable `BriefModuleConstruct` alias in the dump is misleading. The candidate never calls that runtime routine under an invented name.
* `004349c0..00434c80`: a separate unnamed object, `candidates/s8/_unknown/tu_004349c0.c`, profile `ot`. Evidence: a `ret` initializer at `004349c0`, reproduced by an empty inline constructor on the global point; its code follows the preceding object's constructor/destructor helpers. Splitting restores the preceding helper's own return instead of compiler fall-through into an ordinary empty function. This is a supported object-boundary inference, not original path evidence. The primary object's last STRICT extent counts 14 bytes; its uncounted two-byte tail alignment is not claimed.
* `00448d74..0044950c`: `pop\pdeath.c`, profile `plain`. Retained the leading active-field clear with the death routines: it has no separate path/alignment evidence, and all four extents prove in this object. The Surface constructor wrapper is compiler-generated COMDAT code, not a hand-authored replacement. One final linker-fill byte is not counted.

Names are working labels. Noise's full class ABI and the parked terrain structures remain provisional. `Noise::Noise` and the module registration are compiler-generated from a real global class object. Noise cleanup helpers expose the observed initialization/release API. The parked local lifecycle model needs further work: forcing both constructor and destructor inline instead emits 32/20-byte class COMDATs rather than the original 16/14-byte trailing helpers. See `build/s8/terrain_inline.objdis.txt` and `build/s8/pre_noise_inline.c`. This model limitation is not a TU proof claim.

`Noise` storage (444 bytes), the Flic unknown fields, and unnamed Search words are measured but incompletely typed data layouts. Their byte storage represents data, never executable code. The pdeath assertion is on source line 51. No `#line`, assembly, machine-code arrays, oracle edits, or byte patches are used.
