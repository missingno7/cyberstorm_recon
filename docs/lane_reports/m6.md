## Codegen facts (new evidence, 10.6 wpp386)
- Negating a byte through an int temp: `int t = b; t = -t;` vs `int t = -b;` changes which values Watcom keeps
  in registers across the whole function. It moved a parameter into a register (EDI) and switched the
  index*12 fold, giving BestLocSubCandidate STRICT, but did nothing for its sibling.
- Inlined switch functions (-oe): passing an outer switch variable whose value the case fixes leaves the inline
  compare tree unfolded, with the constant in a register; the Score pass turns the equal-constant compare into
  `cmp reg,reg`. In ActorQuery a literal argument folded (case 208). In SendEvent the candidate's literal
  arguments also stay unfolded, so the rule depends on context.
- A local holding a global array's address (`char *m = buf;`) used as a call argument gives `mov esi,imm32` once
  and `push esi`. The array name in every call gives `push imm32` each time (LogicCheckActorCollision, 21 B).
- A byte flag widened into an int and then incremented (`U8 c = a == 0; int d = c; d++;`) gives
  `xor r,r; sete al; mov rl,al; inc r`. `(a ? 1 : 2)` and `(a == 0) + 1` give `and eax,0xff; lea`.
