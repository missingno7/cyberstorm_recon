## Code-generation findings and negative evidence

All findings below are limited to pinned 10.6 C++, `-4s -s -bm -oe`, these TUs.
They are proposals for the integrator's docs, not edits to canonical docs.

1. **A bounded random inline helper preserves division.** Directly narrowing
   `next_link_seed(...) % 16` to ushort gives byte masking, making Top::Open
   316 bytes instead of 318. `inline unsigned MenuRandom(unsigned maximum)`
   returning `next_link_seed(...) % maximum`, called with 16, retains
   `mov ebx,16; xor edx,edx; div ebx` and makes the 318-byte function STRICT.
   Evidence: `top-second.txt` vs `top-third.txt` in build/s13.
2. **Default arguments affect calls even when values are unchanged.** In the
   16-case animation switch, declaring `SoundTrigger(unsigned,int=0)` and
   omitting its zero argument reproduces `xor eax,eax; push eax` at cases 1/8.
   Explicit zeros emit shorter `push 0` there. The final 1,350-byte switch is
   STRICT. Replacing the counter accessor with its direct value field also
   removes a cached EDI and its save/restore. `top-second.txt` / `top-third.txt`
   retain the combined change and differences; these two effects were not
   independently separated, so treat their attribution as supported context,
   not a universal compiler rule.
3. **Default constructor arguments affect static-init constant reuse.**
   `MenuNumber mainNumber(-1,18)` reuses ESI=18 for a state store and changes
   the initializer register/size. Giving that constructor defaults (-1,18)
   and writing `MenuNumber mainNumber;` yields the original EDI=11 reuse and
   STRICT 662-byte initializer. It also supplies the correct constructor
   thunk for the MenuNumber type signature. `main-diff.txt` / `main-second.txt`.
4. **An early return controls Start's tail sharing.** Six complete branch
   spellings were tested by `experiments/start.tpl`; only choice [1],
   `if (failure) { ShowRestart(); return 0; } success...return 1;`, is STRICT.
   Falling through to the final return moves the restart message behind the
   success body and changes the first conditional displacement at +0x1b.
   Evidence: `start-variants.txt`, 6/6 compiled, winner 1 STRICT / 0 differing
   bytes. Capturing all four unavailability bits as byte temporaries before
   testing them reproduces AL/AH/DL/DH precomputation.
5. **The image accessor changes Highlight's frame.** With scalar `image`
   indices, comparing direct array addresses against the inline `Image(int)`
   accessor at both image calls gives eight complete combinations with the
   frame accessor/direct frame-member choice. Only [0,1,1] is STRICT: the
   frame accessor plus direct image-array addresses at both calls. Any image
   accessor adds `mov ebp,esp` at +4 and prevents EBP holding `this`.
   Direct frame-member access removes the LEA/load shape at +0x3f.
   Evidence: `experiments/highlight_accessors.tpl`,
   `build/s13/highlight-accessors.txt`: 8/8 compiled; winner 1 STRICT / 0 diff.
6. **Negative scope probe:** moving the mask declaration outward, adding an
   outer index declaration, and switching frame access did not fix the frame
   while image accessors remained. The 12-combination scope experiment had
   10 compilable variants, none STRICT, and two intentionally ill-formed
   combinations (assignment with no mask declaration). It was abandoned;
   these two compile errors are not matching attempts. Evidence:
   `experiments/highlight_scope.tpl`, `build/s13/highlight-variants.txt`.
7. **Context matters for extent tails.** Isolating Highlight changed its tail
   sharing and extent but retained the wrong frame when image accessors were
   present. `plain` likewise did not solve it and stopped required inlining
   elsewhere. Full-TU `plain-oe` is the successful configuration. The single
   differing byte in Update was its reference to the jump table following
   Highlight; fixing Highlight made Update STRICT without editing Update.

Additional corrections: original empty-looking format at 0048a1dd is `" "`,
not `""`; fixing it turns SetText from UNBOUND into STRICT. MenuLabel's packed
size is 49 bytes (0x31), not its 52-byte global stride. Adding three tail bytes
breaks its type signature. Restoring size 49 and its real default constructor
arguments makes the virtual destructor STRICT. Top SetControls needs source
case order 0,1,3,2; its second 0/default loops use `<=18`, whereas its initial
hide-all loops use `<18`. These distinctions reproduce the jump table and all
582 bytes.
