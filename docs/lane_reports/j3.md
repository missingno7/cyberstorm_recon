## Binding and reproduction details

The shell source now uses existing symbol names for the newly exposed screen calls, campaign operations and globals. The dry run reports one exact-signature hypothesis for BioScreen::Open at 0040bf78. In ProcessInput, 0040186d pushes the string address, then the request and receiver are pushed, 0040187b calls 0040bf78, and 00401880 cleans up 12 bytes.
