## New code-generation observations with evidence

These are lane-local observations for the integrator to reconcile into docs/codegen_rules.md; no canonical documentation was edited.

1. **Member context can change register allocation even when this is otherwise unused.** ActorApplyDamage as a member becomes STRICT (556 bytes); a broad conversion of other actor functions to methods loses proofs (`actor.damage.member.txt`, `actor.methods2.txt`). Equal as a member fixes the two-byte parameter-register swap (`equal_method_variants.c`, `equal_method.variants.txt`, 42-byte STRICT result). This is specific evidence, not a general requirement to convert every function.
2. **Postincrement expression lifetime matters.** `actorVoices[actorVoiceCycle++ % 6]` yields the original 109-byte ActorVoice; a separate increment yields a 101-byte body with different storeback/register lifetime. Final delivery comparison proves the selected form.
3. **Checksum source-order capture matters.** Compute the remaining count, then a named char pointer to the tail before calling Crc16. It emits ADD EBX before PUSH EAX and matches 88 bytes; four of eight combinations match (`crc_variants.c`, `crc.variants.txt`).
4. **Wide arithmetic followed by explicit narrowing differs from a byte addition.** ActorCondition matches 113 bytes when descriptor morale is captured before adding level, and the offset+threshold sum is computed as int before conversion to U8. It removes an extra ESI save and prevents a byte ADD (`condition_order_variants.c`, six compiled, [1,0] STRICT; earlier condition variants did not match).
5. **Structured else can prevent cross-function tail sharing.** Fixup's -1 arm followed by else, without an early return, emits the original 40-byte body; the early-return spelling collapsed to a short shared-tail version. Three of six `fixup_variants.c` alternatives are STRICT.
6. **Explicit return after increment and declaration order affect TrainingCost.** `++s->skill; return 0;` emits XOR EAX then INC memory instead of a combined LEA/store. Declaring middle immediately after current and before low/high fixes temporary offsets. `training_variants.c` tests 3 return models x 2 declaration orders; two results STRICT at 307 bytes, two differ by four bytes, two by 176.
7. **Member plus default-argument context resolves GetName's frame.** Seven free-function/default placements did not match; four of seven member forms do (`getname_member_variants.c` / receipt). Selected 85-byte body and its inlined AttemptStart copy retain the real default name/max length arguments.
8. **Geometry switch preserves original backward control flow.** `switch(GetMode())` with case 0 and default emits the backward jump to shared height initialization. If/else hoists it and is two bytes shorter. Six models in `geometry_variants.c` produce STRICT DrawText (108), Search (150) and SigsJoin (150) with the switch, while Wait still has an external return-target difference.
9. **An inline visibility setter preserves load/mask/store at zero.** Direct field bit clearing optimizes to memory AND; `SetVisibility(0)` emits the original full load/AND/store. Combined with Controls source case order 0,3,2,1,4 this recovers its 1339-byte body, leaving only a shared-return displacement. This setter can change inlining/allocation adversely in AttemptStart; no universal rule is claimed.
10. **Typed Flic accessors affect pointer lifetime.** Actual `Flic::Open(long,int=100,int=0)` and inline SetLoops recover Open's 935-byte body except the shared epilogue target. Raw/invented wrapper forms differed more (`open.variants.txt`). Inline CurrentFrame similarly recovers Hover's original early saves/member-address sequence, though its image loop remains DIFF.
11. **Selector width and inclusive bounds matter.** Selection is a DWORD load masked with 255, not a byte load. Explicit `mode == 0`, rather than a bare char truth test, reproduces zero extension. Update requires the evidenced unused third Hover argument and inclusive `hover >= 1 && hover <= 4`; `>0 && <5` compiled to TEST/JLE rather than CMP/JL and was three bytes short. Corrected Update is STRICT at 358 (`update.corrected.txt`, `update.bounds.txt`, final receipt).
12. **Global unwind state belongs to destructor-bearing objects.** At each selector pair, an 8-byte trivial-dtor selection object followed by a 40-byte destructor-bearing control causes two constructor calls but only one unwind-state advance. Modeling one 48-byte object caused destructor-item addresses to disagree by 8. Splitting real global objects recovers the full 1127-byte initializer, DATA and CONST2. No manual runtime calls or state writes are used.
13. **Helper-interface experiments can normalize completely.** All six nonbaseline scalar models and all six fixed-point models compile to identical DIFF caller sequences for the listed functions. Pointer/reference, implicit this and signed-pointee substitutions alone do not resolve those callers in this profile. The complete sources and try receipts preserve this negative evidence.
