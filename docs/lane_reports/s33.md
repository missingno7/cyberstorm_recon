## Compiler facts for integrator review

1. **Global class array initialization.** Under ot, 2000 RenderItems with out-of-class empty inline ctor and implicit destructor produce the exact 32-byte initializer at 42b940 and STRICT type metadata. An explicitly written empty destructor adds registration and yields a differing 48-byte initializer. Evidence: six `display_array_class_0..5.c` complete-TU probes, first three STRICT, last three differing. Use actual global objects instead of a manual runtime call.
2. **Byte predicate spelling.** An inlined visibility method returning bare `!values[index]` keeps byte compare/set shape. The equality-to-zero spelling widened the intermediate in these geometry contexts. Evidence: six `display_bounds_bool.tpl.c`, plus STRICT bounds, point projection, consider and pick functions.
3. **Aggregate/helper context matters.** A named rectangle destination pointer selects the required copy registers (DisplaySetRect STRICT 80). Point copy construction, reference-returning +/- operators and Y() lvalue allow STRICT bounds/projection/pick. Inlining a generic void** sort helper in process produces the correct frame and STRICT 480-byte DisplayProcess; manual expansion did not. Evidence: rectangle, bounds, pick and process templates listed above.
4. **Signed branch type is observable.** In DisplaySubmitElement, signed lower>0 with buffer path first yields STRICT 416; unsigned test changes the branch instruction, while reversed direct/buffer branch order also differs.
