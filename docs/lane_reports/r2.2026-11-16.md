### The source error: GridPoint is passed BY VALUE

Both functions take a `GridPoint` by value, not a `GridPoint *`. GridPoint has user constructors, so Watcom's caller
builds a temporary and passes its address (codegen row 34). The callee treats that hidden pointer as memory:

- SimCenterOn: the original loads `&s->view` into EBX first, then a fresh copy of the hidden pointer into EDI for the
  compare (`mov eax,[ebx]; cmp eax,[edi]`), then reloads it into ESI for GridPointToIndex and the copy. A pointer
  parameter is loaded once and cached, which is the D112 every lane saw.
- SimPanBy: every use of `d` reloads `[esp+0x20]` (7 reloads). `f_0047efb0((Point *)&d, ...)` rotates the callee's
  own copy.
- SimPan must build the temporary in place: `SimPanBy(s, GridPoint(dx,dy));`. A named local `GridPoint d` passed by
  value costs SimPan 59 B (extra copy).
- SimSetFocus calls `SimCenterOn(s, s->focus->action.position)`; the inline copy then shows the original's spilled
  `[ebp-0xc]` hidden pointer and the `[ebp-0x18]` temporary. SimSetFocus goes from D901 to D22.
