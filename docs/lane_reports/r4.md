## New codegen facts (this lane)
- C++ by-value class parameter with a user constructor vs extern "C" prototype: with C++ linkage the caller builds the
  temporary and pushes its address (+EBP frame); with extern "C" Watcom pushed the members (UpdatePreview, 4 bytes).
- In plain-oe/ot-oe TUs, an inline helper returning `v<0?-v:v` coalesces value and result; the same expression
  written in place keeps them in two registers with a copy in each arm (f_00445e23 abs). Same for Owner()-style
  `u?u->x:0` (LogicCheckActorCollision). Check for this when the original shows `mov edx,ecx; neg edx / mov edx,ecx`.
- A local initialized before an if/else (`int score=0; if(..) score=1; else if(..) ...`) lets Watcom reuse a register
  already known to hold 0 and moves an inline call's result to another register (ActorListTransfer).
