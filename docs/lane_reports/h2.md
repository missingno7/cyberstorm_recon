- SimGame::Open 0044aff0 (sim.c): `view.flags=view.requested;` before `view.spare=100;`; bookmarks copied with
  `for(int i=0;i<13;i++)bookmarks[i]=view;`; the colour profile is
  `const unsigned long *mission=missionScripts[mainSelectedMission]; ...=mission[13]; ...=mission[7];` (`short mainSelectedMission`,

  PilotSetState also no longer keeps the `old` copy (`s->previousMode=s->selectedMode;`, kept on its own line so later
  assert lines stay put). `previous` is read before `GridPoint point(...)`: D365 -> D106.
- LogicActorList::ResetActorState 004647c4, ::CalculateActorValues 00464a96, ::NotifyActorLinks 00464c58, ::SelectActor 004643c7
  (lactors.c): rewritten from the listings with typed inline predicates in the style of the existing `Live()`:
  `IsUnit()` (type == 30), `Ready()` (unit && ((ActorUnit *)unit)->alive && ...->info->Active() && !...->inactive),
  `Unlinked()` ((flags & 2) == 0), free inlines `ActorArmed(a)` (ActorArrayGet(a,7) != 0) and `LogicFlag8()`.

  CalculateActorValues uses `inline AddDirection(int *average, int kind, int direction)` with its own `int contribution[2]`
  (this gives the stack layout), `actor->name != other->name` and `if (force) ... else ...`. SelectActor reuses the `actor`
  parameter as loop variable and result, puts the `actor != 0` branch first, and calls `Flag2()` in the tail.
  NotifyActorLinks walks links with `ActorAt(linked->linkedIndex)`.
- HercListItems 00439997, HercFillItems 00439f6e (tu_004394e0.c): `(mask&HercWeapons[i].words[0])` (mask first; memory operand
  order) and `session->Level()>=...level` with `int SessionLevel::Level(){return level;}`. Both bytes are widened and compared
  signed (`xor/mov; cmp; jl`), which the original does. Same change for the specials loops.
- f_0041b7a1 0041b7a1 (hbupgrad.c, dependent, not a target): becomes STRICT once f_00419413 uses
