## Codegen facts (new evidence)
- Tail sharing across functions stops at an object boundary. When a rebuilt function newly offers a tail that a
  later STRICT function would jump into, but the original does not, that is evidence for an object cut
  (tu_004413e0 / actorver).
- A for loop with an int counter whose first test is constant-true becomes a pointer compare, with entry by jmp into
  the body (SimPaletteCycle). A do-while or a pointer-compare for gives a different layout.
- A byte local assigned on both arms (`if(++x<end) c=x; else c=x=first;`) gives a shared tail with a register copy
  `mov bl,cl`. Increment in memory comes from `++` inside the condition, not from a statement before it.
- An inline helper that modifies its parameter (`--levels`) keeps a parameter copy in every inlined expansion, e.g.
  `mov edx,ebx; ... lea edx,[ebx-1]`.
- An extra named local `time` before `phase = time&1` changes register allocation for the whole function
  (UnitDamageIndicator).
