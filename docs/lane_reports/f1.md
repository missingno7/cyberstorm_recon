## Reconstruction details

- `PrepareActorDescriptor` issues seven calls to `CurveInit`. The seventh call at 00438367 initializes the curve at descriptor offset 0x16a. This corrects the six calls in the earlier census.
- `UnitFogObject` copies the slot-specific record size from `HercItemTables[slot].size`. Calling the inline size lookup from `memcpy` resolved the last 23 differing bytes. The item table layout and equipment helper signatures agree with the neighboring equipment object.
- The scalar curve evaluators compare signed coordinates and divide by signed widths. `CurveSlope` interprets the input as unsigned fixed point with 12 fractional bits and uses unsigned division for the interpolation. Returning the already-shifted endpoint values before the switch reproduced the shared endpoint block at 0043b716.
- `SimLoadPalette` maps world 99 to record 24, writes 99 to its ID field and copies 104 bytes. `HercPrepareAssets` copies record 23 into `g4c9234`. Both release the loaded resource.
