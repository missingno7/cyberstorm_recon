A literal address reproduces the instruction bytes but loses the relocation. This supports testing the TU-level static-constructor/object-declaration form next.

The remaining difference is the saved-register prologue; the source now mirrors the target's reachable and conditionally unreachable loop edge.

The chat length macro is physically on line 140 and passes literal `140`.
- Renaming external references to the existing canonical C++ names preserved matched call bytes for `MessageValid`/`MessageDispatch`, `MenuMessageBasic`/`MenuSend`, `LogicTextAppend`, `LinkBeginThread`, and `MenuNetwork::IsRemote`. In particular, the class-member `gMenuNetwork.IsRemote(i)` form remains STRICT in `update_chat_menu`.
