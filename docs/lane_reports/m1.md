- 0043ae77 HercSelectHit: D224 -> D141. The function is now 429 B, the original size (it was 426).
  The mount descriptor is used through inline members on `c->mounts[i]`:
  - `U8 &Allowed()` returns a reference. This gives the original `imul ecx,i,1a; lea eax,[c+1b]; add ecx,eax; cmp byte [ecx],0`.
    Value, bool and int returns give `mov al/test` or a setne.
  - `int Weight(a,x,b,y)` returns `weights[a]*x/100+weights[b]*y/100`.

  A named `Mount *m` or `Mount &m`, or `Chassis::MountAt(i)`, promotes u to EBP (frame 0x70).
  Two differences remain:
  1. The weight sum. The original accumulates in the first term's EDI (`add edi,eax; add edi,bias`); the candidate has `lea edx,[edi+eax]`.
  2. The u reload before HercItemEfficiency uses ECX in the original and EBP in the candidate.

  `Weight2` (`w=A; w+=B; return w;`) fixes the accumulation, but then u and c trade registers, unless chance is read through an
  accessor that does not match the original (D101/D113).
