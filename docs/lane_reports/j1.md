## Source change

The rejected-start path sits inside an explicit `else` of `if (s->canStart)`. It sets visibility on the five buttons through the existing `SetVisibility(5)` method and draws the four validation messages directly in that scope. The exact build materializes the 44-byte button address, spills the first message pointer to `[ebp-4]` at `+1b7`, and restores the stack at `+377`.

With the original local names and draw expressions, the explicit `else` plus the original direct flag assignment gives 896 bytes and 650 differing bytes. Changing that assignment to the existing setter in the same scope gives 894 bytes and zero differences. An intermediate inline error-drawing helper reached all six original branch targets, but left seven render-output stack offsets different. The submitted source uses the direct calls and matches all seven offsets.

The fresh dry run reports STRICT for the entire main `_TEXT` segment. A whole-object match remains unproven because of separate unplaced COMDATs and differing type signatures.
