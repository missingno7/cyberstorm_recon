## Encoding details

- `xchg ecx, ebx` emits `87 CB` at 0047f8c7 and 0047f8d2. The reversed spelling produced the two differing ModR/M bytes in the first 4.0 comparison. `xchg ebx, eax` selects the original accumulator short form.
- `jcxz root_done` in USE32 supplies the address-size prefix seen at 0047f903. `bsr ecx, edx` supplies the high-set-bit scan at 0047f8fb.
- `[ebx + eax]` retains EBX as the table base and EAX as the index in the palette loads. Operandless `rep movsb`, `rep movsd`, `rep stosb` and `rep stosd` use the implicit string operands. `push ds` and `pop es` set the destination segment.
- `jmp SHORT` names the packet-loop back edges. `ALIGN 4` emits the single code NOP before the following framed procedure in both executable revisions.
- The source preserves the distinction between `adc esi, 0` in the fractional remap kernel, `adc esi, [stepXWhole]` in the general remap kernel, and `adc esi, edx` in the raw and blended kernels.
