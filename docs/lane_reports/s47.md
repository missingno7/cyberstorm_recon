- settings globals with file-scope pointer literals emitted their strings at the end of CONST. Local static metadata with an automatic format pointer reproduces both initialized segments; intermediate probes remain under candidates/s47/settings_*.c. The original names/scope are not established by byte equality.
- Extending a correct _DATA prefix and moving an already-recorded object to CONST are both data losses under the current gate, even when every accepted function is still STRICT and tucheck reports COMPLETE. No acceptance exception was used.
- A single combined pdeath main segment cannot cross the interleaved Surface COMDAT. The independent code/CONST boundaries support splitting the object; its already accepted function ownership currently prevents a lost-0 migration.
