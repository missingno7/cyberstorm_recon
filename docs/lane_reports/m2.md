## Codegen facts (new evidence)
- wpp386 -oe inline cost is measured on the callee's own body: a call of an inline helper costs ~9 units, so wrapping a body in
  an inline helper makes its caller inline it; an inlined copy keeps the same dead-store branches as the out-of-line copy.
- A conditional store to a variable that is overwritten later leaves its branch chain with a final `jne +0`; an empty
  if-body or a store to an unused variable removes the whole test.
- Early-return guard vs wrapping if changed register homes in QueueReceive (D3 -> STRICT).
- `DrawPoint step(x)` (direct init) and `DrawPoint step = x` compile differently with a user copy ctor in a stack context.
- A function-static array of class objects initialised with `T(a,b)` constructor calls compiles to scalar constant stores
  (constants cached in EDX/ESI/EDI/ECX); a class whose member array has a default ctor calls __wcpp_2_ctor_array_ instead.
