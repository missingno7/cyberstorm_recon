## New codegen facts (with evidence)

- An inline helper that takes scalars by value gets stack homes for those parameters when it is expanded (ot):
  DisplayMax(int,int) produces `mov edi,1; mov [esp+20],edi; cmp eax,edi`, both in DisplayZoomArea and in
  DisplayConfigure. A `const int &` parameter does not give this pattern. This explains frames that are
  "4 bytes short" whenever a MAX/MIN helper is involved.
- Function-local statics and file statics in _BSS come out in reverse declaration order: a local static
  declared later in the file is placed lower in BSS (ScriptRef/ScriptString).
- A switch tree is shaped by every listed case value, including empty ones that share `break` (MenuChat::Event,
  keys 1 and 77).
