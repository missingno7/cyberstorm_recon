# Compiler facts reported by worker lanes (appendix to codegen_rules.md)

Rows as the lanes reported them, tagged with lane and date. The integrator has NOT re-verified each one: treat a row
as a lead that worked once in the named function, and search this file (do not read it top to bottom) when a symptom
looks familiar: `grep -i "switch" docs/codegen_rules_lanes.md`. A row that proves itself in a second file should be
moved to docs/codegen_rules.md.
